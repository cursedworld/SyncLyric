# SyncLyric

Локальное приложение для синхронизации текста песен с аудио (MP3/WAV/FLAC)
и автоматической генерации LRC-файлов с точными таймингами.

## Требования

- Python 3.9+
- **FFmpeg** — должен быть установлен и доступен в переменной окружения `PATH`
  (скачать: https://ffmpeg.org/download.html)
- CUDA-совместимая видеокарта (опционально, для ускорения Whisper)

## Установка зависимостей

```bash
pip install -r requirements.txt
```

При первом запуске faster-whisper автоматически скачает модель `medium`
(~1.5 ГБ) в локальный кэш.

## Запуск

```bash
python main.py
```

## Как пользоваться

1. Перетащите аудиофайл в левую зону (или выберите через клик).
2. Перетащите файл с текстом песни (`.txt`) в правую зону.
3. Выберите язык из списка или оставьте **Auto**.
4. Нажмите **«Сгенерировать LRC»**.
5. Готовый файл появится рядом с аудиофайлом (та же папка, то же имя, расширение `.lrc`).
